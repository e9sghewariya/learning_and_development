# Learning Python

## 4. More Control Flow Tools

Description about the Different type of control flow:

-->if statements
        Standard if, elif, else constructs.
        Truth values: non-zero numbers, non-empty strings/lists are True.

-->for loops
        Iterate over elements in a sequence: for x in list.
        Use range(start, stop[, step]) for numerical loops.

--> while loops
        Repeat while a condition is true.
    	break, continue, pass
        break: exit the nearest enclosing loop.
        continue: skip the rest of the current loop iteration.
        pass: does nothing, placeholder for future code.

-->Loop else clause
        Optional else clause after for or while.
        Runs if the loop wasn't terminated by a break.

-->Functions
        Defined using def name(args):.
        Optional return values using return.
        Default argument values: def func(arg=value).
        Keyword arguments: func(arg=value).
        Variable-length arguments: *args, **kwargs.

-->Scopes
        Variables defined inside a function are local.
        Global variables can be accessed with global.
