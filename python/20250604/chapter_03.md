# Learning Python

## 3. An Informal Introduction to Python

Examples to distinguish presence of >>> and ... prompts

-->Basic Python syntax:
        Python uses indentation instead of braces to define blocks of code.
        Statements must be properly indented.
-->Data Types Overview:
        Numbers: Integers (int), Floating-point (float), complex numbers.
        Strings: Immutable sequences of characters, can be single/double/triple quoted.
-->String operations:
        Indexing and slicing (s[0], s[1:3]).
        Strings are immutable; you cannot modify them in place.
        Use + for concatenation, * for repetition.
-->Built-in functions and conversion
        len(), str(), int(), float().
        Type conversion is explicit.
-->Print formatting
        Use f-strings (f"The value is {value}") for readable string formatting.
-->Lists
        Ordered, mutable collections of items.
        Support slicing, appending, nesting, and all types of data.
-->List operations
        Append: a.append(x)
        Replace slice: a[1:3] = [new1, new2]
        Remove: a[2:4] = []
        Clear list: a[:] = []
        Length: len(a)
-->Nested Lists
        Lists can contain other lists (e.g., a = [[1, 2], [3, 4]]).
